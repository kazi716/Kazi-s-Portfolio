## ✨ Features

### 🖱️ Custom Animated Cursor
- Smooth lag-follow cursor with outer ring + inner dot
- Hover state expansion on interactive elements (links, buttons, cards)
- Magnetic effect on stat cards
- GPU-accelerated with `will-change` and `requestAnimationFrame`

### 📜 Official Credly Academic Transcript & 24 Certifications
- **Pearson Credly Official Transcript** integration (Issued 3 August 2026, Credly ID: `0e8da13e-0d31-461d-acbd-b7761d88f313`)
- **24 Verified Certifications & Skill Badges**:
  - **AWS Cloud (11 Badges)**: Cloud 101, Storage, Networking, Databases, Cloud Ops, Security, Serverless, ML Foundations, Generative AI, SimuLearn Essentials, SimuLearn First Steps
  - **Google Cloud (6 Badges)**: Compute Skill Badge, Cloud Storage & Data Protection, Pub/Sub, API Gateway, Looker, Dataplex Data Mesh
  - **Cisco & OPSWAT (3 Certifications)**: Cisco Networking Basics, Cisco Packet Tracer, OPSWAT Critical Infrastructure Protection (ICIP)
  - **Anthropic AI Fluency (3 Certifications)**: AI Fluency for Students, Teaching AI Fluency Framework, Claude Code in Action
  - **Open Source (1 Badge)**: Open Source Connect Global 2026 (NexFellow)
- **Interactive Vendor Filter Bar**: Filter certifications by vendor (AWS, Google Cloud, Cisco & OPSWAT, Anthropic, Community)

### 📄 Multi-Page PDF Resume Generator
- One-click **"Download Full Resume PDF"** button
- Generates a clean, professional multi-page A4 PDF with exact pagination and footer page numbers ("Page X of Y")
- Includes: Header with Credly ID & profile, Objective, Education, Experience, Skills, Projects, and all 24 verified certifications
- Powered by [jsPDF](https://github.com/parallax/jsPDF)

### ⚡ Live GitHub Dev Pulse
- Real-time GitHub API integration for user `kazi716`
- Displays live stats: **Repos, Active Days, Recent Pushes, Stars**
- Shows top 3 repositories with language and star count

### 🎨 Visual Effects
- Particle network background with mouse interaction
- Scroll progress bar & sticky glassmorphism navigation
- Scanline overlay for subtle tech texture
- Scroll spy section highlighting & back-to-top button
